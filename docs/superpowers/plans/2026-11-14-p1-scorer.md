# P1: The Scorer — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Score any Eyeball-shaped events file (the output P2 will produce) against a trusted event file, per event type, at ±2 s and ±5 s, with team and zone accuracy, and say how it stands against the bar in spec 6.4.

**Spec:** `docs/superpowers/specs/2026-11-13-events-first-action-plan.md`, sections 6.1 (P1) and 6.4. P0 result: GO on m01 and m03; m13 not testable (see `tests/truth/p0_report.md`).

**Architecture:** One module `src/spv/truth/score.py` (pure functions over `TruthEvent`s) plus a `spv truth score` command. Predictions are read with the existing `read_events`, so a P2 output in Eyeball's layout needs no new reader. Truth times are moved onto the video clock with the P0 alignment offsets (`video = file time + offset of that half`). Results go to `tests/truth/score/` (ids and numbers only).

**Tech stack:** Python 3.10+, existing `spv.truth` package, pytest.

## Global Constraints

- Footage shows minors: nothing committed may hold a frame, a local drive path, or a player or team name. Team names may be read into memory to line teams up, never stored or printed.
- Scoring is done on the video clock. Truth event times are `video_s + offset[half]` from `tests/truth/align/mNN.json` (half's median offset; 0 if absent).
- Matching is one-to-one per event kind: each truth event matches at most one prediction and vice versa, the closest pairs first, only within the tolerance.
- Tolerances: 2 s and 5 s (spec 6.1).
- Bar (spec 6.4), scored at ±5 s:
  - goals: recall ≥ 0.90;
  - corners, free kicks in the final third, shots (penalties count as shots): recall ≥ 0.75 and precision ≥ 0.70, each;
  - team right on ≥ 0.90 of matched events (all kinds pooled);
  - zone (third and flank, `zone()` in events.py) right on ≥ 0.70 of matched events that have a place on both sides.
- Branch `feature/04-scorer` from `main`, PR to `main`.

### Task 1: Matching and per-kind recall/precision

**Files:** create `src/spv/truth/score.py`, `tests/test_truth_score.py`.

Produce:
- `BAR_KINDS = ("goal", "corner", "free_kick_final_third", "shot")` — the groups the bar names. `group(e: TruthEvent) -> str | None` maps an event to a group: `goal` → goal; `corner` → corner; `free_kick` with `x >= 2/3` → `free_kick_final_third`; `shot` or `penalty` → shot; everything else → None (ignored by the scorer).
- `to_video(events, offsets: dict[int, float]) -> list[TruthEvent]`: same events with `video_s` moved by the half's offset (missing half → 0). Use `dataclasses.replace`.
- `match(truth, pred, tolerance_s) -> list[tuple[TruthEvent, TruthEvent]]`: within each group, all pairs with `|Δt| <= tolerance_s`, sorted by `|Δt|` then truth `row_id` then pred `row_id`; take greedily, each event at most once. Deterministic.
- `per_group(truth, pred, tolerance_s) -> dict[str, dict]`: for every group in `BAR_KINDS`: `{"truth": n, "pred": m, "matched": k, "recall": k/n or None, "precision": k/m or None}`.

Tests (write first): exact-time match; a prediction 3 s off counts at 5 s not at 2 s; one prediction cannot match two truth events; different groups never match; free kick at x 0.5 is ignored, at x 0.8 is `free_kick_final_third`; penalty groups as shot; `to_video` shifts by half; recall/precision None when a side is empty; determinism.

Commit: `feat(truth): match predicted events to truth per event type`.

### Task 2: Team mapping, team and zone accuracy

**Files:** modify `src/spv/truth/events.py`, `src/spv/truth/score.py`, tests.

- `events.team_names(path) -> list[str]`: the team names in order of first appearance, read the same way each reader assigns A/B (Eyeball CSV `Team`, Eyeball XML TEAM label, StatPadder `team`). Never stored on `TruthFile`. Add a test that `read_events` repr still holds no names.
- `score.team_map(truth_names, pred_names) -> dict[str, str] | None`: maps prediction letters to truth letters by name. Names are compared case-folded with spaces collapsed; a pair matches when one contains the other. Return `{"A": "A", "B": "B"}` or `{"A": "B", "B": "A"}`; None when the names do not decide it.
- `score.accuracy(pairs, mapping) -> dict`: `{"team_right": r, "team_of": n, "zone_right": z, "zone_of": m}` over matched pairs: team compares `mapping[pred.team]` to `truth.team`; zone compares `zone(x, y)` of both, counted only when both have a place.
- When `team_map` returns None the caller uses identity and the result says `"team_mapping": "unverified"`.

Tests: names in either order map correctly; unrelated names → None; accuracy counts with and without places; swapped mapping.

Commit: `feat(truth): team and zone accuracy for matched events`.

### Task 3: The bar and the score record

**Files:** modify `src/spv/truth/score.py`, tests.

- `score_match(truth, pred, offsets, mapping) -> dict` with keys `"at_2s"` and `"at_5s"` (each the `per_group` result), `"accuracy"` (at 5 s), `"team_mapping"` (`"by name"` or `"unverified"`).
- `bar(result) -> list[dict]`: one row per bar line of the spec (goals recall; corners, free kicks in final third, shots — recall and precision; team; zone) with `{"test", "value", "need", "pass"}`; a value of None does not pass.
- `score_markdown(match_id, label, result) -> str`: a table of groups (truth, predicted, matched, recall and precision at 2 s and 5 s), the accuracy line, and the bar table with pass/fail. Numbers as percentages with no decimals; None as `-`.
- `pool(results: list[dict]) -> dict`: sums truth/pred/matched and accuracy counts across matches and recomputes the ratios, so the bar can be judged over all scored matches (the spec scores on the held-out P0 matches together).

Tests: bar pass/fail edges (exactly at the threshold passes), None fails, pooling sums correctly, markdown contains the bar rows.

Commit: `feat(truth): judge scores against the proof-of-concept bar`.

### Task 4: `spv truth score`

**Files:** modify `src/spv/truth/cli.py`, tests.

`spv truth score mNN PRED_FILE --label LABEL`: reads the match's registered event file and `PRED_FILE` (any format `read_events` takes), aligns truth with the match's saved offsets, maps teams by name, scores, writes `tests/truth/score/mNN-LABEL.json` (the result dict, ids and numbers only) and `tests/truth/score/mNN-LABEL.md`, prints the markdown. `--label` must match `^[a-z0-9-]{1,40}$`. `spv truth score-pool --label LABEL` pools every `tests/truth/score/*-LABEL.json` and writes/prints `tests/truth/score/pool-LABEL.md`. Errors: one line, exit 1. Exit 0 otherwise (the bar is information, not an error).

Tests: CLI flow on the sample files (truth scored against itself gives 100% everywhere and every bar line passes where the group has events); bad label refused; pool writes its file.

Commit: `feat(truth): spv truth score commands`.

### Task 5: Check the scorer on the real P0 matches (controller)

On m01 and m03 (the testable P0 matches):
1. Score each truth file against itself (`--label self`): must be 100%/100% for every group with events and team/zone 100%.
2. Score against a degraded copy made in the scratchpad (never committed): every group's times shifted by +3 s, 30% of events dropped and a handful of false events added, teams kept. Expected: recall about 0.7 at 5 s, near 0 at 2 s, precision lower. Commit the `-degraded` results only if they contain no names or paths.
3. `score-pool` both labels.
Record the outcome under "Notes" in `tests/truth/score/README.md`: what was checked, and that real predictions arrive in P2.

## Self-review notes

- Spec P1 asks for recall and precision per event type at ±2 s and ±5 s (Task 1), team and zone accuracy (Task 2), reading an Eyeball-shaped file on both sides (`read_events`, Task 4), run on the P0 matches (Task 5).
- Only the bar's event groups are scored; kick-offs, throw-ins and goal kicks are not in the proof of concept's scope (spec 2, priorities 1 and 2) and are ignored.
- The spec's "free kicks in the final third" uses the truth file's x; a prediction's group uses its own x, so a free kick placed in the wrong third counts as unmatched in that group. This is intended: the bar treats the place as part of the event.
